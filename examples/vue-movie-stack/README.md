# Riffle: Vue movie stack

A fanned stack of eight invented movie posters, built with `@rpxl/riffle/vue`'s
`useRiffle` composable and its `v-riffle-root` and `v-riffle-card` directives.
Each poster is a CSS gradient, since no licensed artwork is used, and the
title, year and a "3 / 8" readout update as the stack changes. Run `pnpm
--filter vue-movie-stack dev` from the repository root and open the printed
URL.
