# Riffle: React movie stack

A fanned stack of eight invented movie posters, built with `@rpxl/riffle/react`'s
`<Riffle>` component and driven by prev, next and drag. Each poster is a CSS
gradient, since no licensed artwork is used, and the title, year and a
"3 / 8" readout update as the stack changes. Run `pnpm --filter
react-movie-stack dev` from the repository root and open the printed URL.
