# Riffle: vertical stack

A vertically fanned stack of six invented playlist tracks, built with
`@rpxl/riffle/react`'s `<Riffle>` component set to `axis: 'y'` so the cards
cascade downward instead of across. Focus the stack and press the up or
down arrow keys to browse (a visible hint names the keys), or use the prev
and next buttons; each track is a CSS gradient, since no licensed cover art
is used. Run `pnpm --filter vertical-stack dev` from the repository root
and open the printed URL.
