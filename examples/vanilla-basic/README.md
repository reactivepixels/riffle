# Riffle: vanilla basic

A single HTML file showing Riffle with no framework and no build step: five
coloured cards fanned into a stack, dragged, flung or stepped with buttons.
Run `pnpm dlx serve examples/vanilla-basic` from the repository root and open
the printed URL, or open `index.html` directly in a browser. Full docs and
API reference: https://reactivepixels.github.io/riffle
