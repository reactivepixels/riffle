# @rpxl/riffle

## 0.1.0

### Minor Changes

- f619e5a: Initial release. A framework-agnostic, physics-based cycling card stack with
  keyboard navigation, `getLabel` accessible names, `'auto'` card sizing, a complete
  `update()` for every option, and `createAdapterHandle` for building framework adapters.
  Ships with a React entry, `@rpxl/riffle/react` (`useRiffle`, `useRiffleState` and
  `<Riffle>`), and a Vue entry, `@rpxl/riffle/vue` (`useRiffle`, the `v-riffle-root` and
  `v-riffle-card` directives, and `<Riffle>`).
